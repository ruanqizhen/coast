## 🎮 如何开始

1. 打开浏览器访问游戏页面，点击 **"开始游戏"**
2. 跟随 5 步新手引导完成基础操作
3. 或者直接关闭引导，自由探索

---

## 🕹 基础操作

| 操作 | 方式 |
|------|------|
| **平移视角** | 鼠标左键拖拽 |
| **旋转视角** | 鼠标右键拖拽 |
| **缩放** | 滚轮 |
| **双击设施/游客** | 居中对焦并弹出信息卡 |
| **建造设施** | 底部栏选择 → 点击地面放置 |
| **旋转设施** | 放置前按 `R` 键 90° 旋转 |
| **铺设道路** | 底部「道路」标签 → 选择类型 → 点击/拖拽铺设 |
| **取消建造** | 右键（设施模式）/ 底部取消按钮（道路模式） |
| **游戏速度** | 顶部栏 ⏸ ×1 ×2 ×4 |
| **截图** | 顶部栏 📷 按钮，导出 1920×1080 PNG |

## 💰 经营策略

### 新手开局（Day 1–30）

1. **先铺路，再建设施**。道路从入口延伸，所有设施必须连通。入口在地图底部中央。
2. **首建：旋转木马 + 薯条摊 + 洗手间**。成本低，满足基本需求。
3. **雇佣 1 名清洁工**，放在餐饮区附近。
4. **门票免费**。初期游客少，免费入园能最大化客流量。
5. **研发预算设 $200/月**，优先解锁「家庭互动」（碰碰车）。

### 中期发展（Day 30–90）

6. **建造过山车**。过山车吸引力高，是客流核心驱动力。用随机生成快速获得可运营轨道。
7. **平衡设施类型**。刺激设施吸引青少年，温和设施吸引家庭。多样化覆盖所有年龄组。
8. **雇佣修理工**，覆盖过山车和高价值设施区域。
9. **调整票价策略**。高吸引力设施（过山车）可定价 $6–$8，普通设施保持 $3–$5。
10. **监控满意度**。跌破 60 时立即检查：垃圾是否过多？是否有故障设施？是否需要更多洗手间？

### 后期扩张（Day 90+）

11. **科技树优先运营线**。「寻路优化」提升游客决策速度，「智能调价」自动优化票价。
12. **冲刺星级**。满意度 ≥ 90 + 游客 ≥ 800 可达 ★★★★★。需要大量景观设施提升环境分。
13. **贷款策略**。利率 1.5%/月，最多借 $5,000。只在扩张地块或建造弹射过山车时使用。
14. **天气应对**。看到暴雨预报时提前放置天气帐篷，保护户外游客。

## 💡 进阶技巧

- **游客情绪可见**：每个游客头顶有表情圆标 😄🙂😐😠，点击游客可查看详细需求和想法
- **拖拽铺路**：在道路模式下按住左键拖拽，可以连续铺设
- **过山车随机生成**：编辑器内点「随机生成」自动创建可运营的多样化轨道
- **设施改名**：点击设施信息卡上的名称可以自定义命名
- **VIP 游客**：偶尔有网红博主到访，消费力极强，满意度影响次日客流
- **拆除退款**：首月内拆除退还 70%，之后退还 40%
- **过山车 G 力**：编辑器实时显示预估 G 力，超过 6G 会有警告
- **收入弹窗**：每次产生收入时飘出 +$X 金色动画
