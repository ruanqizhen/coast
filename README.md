# 🌊 海岸游乐园 Coast

> 一个运行在浏览器里的 3D 主题公园模拟经营游戏
> **Build → Attract → Optimize → Expand**


![](image.png)


---

## 🎮 项目简介

**Coast** 是一款基于 Web 的 2.5D / 真 3D 主题公园模拟经营游戏。
玩家从一块 64×64 的空地起步，通过建造设施、管理游客、优化经济与运营，最终打造五星级公园。

👉 核心目标：在 **碎片化时间（15–30 分钟）内完成一次完整经营循环**

---

## ✨ 核心特性

### ⚡ 即开即玩

* 无需安装，打开浏览器即可运行
* 支持 URL 分享
* 冷启动 < 5 秒

### 🧠 真实游客 AI

* FSM + 效用评分系统
* 每个游客拥有独立：

  * 需求（饥饿 / 疲劳 / 恶心等）
  * 偏好（刺激程度 / 年龄组）
  * 决策逻辑（路径 + 排队 + 消费）

### 🎢 可自定义过山车（Phase 3）

* 分段轨道拼装
* 实时 G 力校验（>6G 禁止运行）
* AI 安全检测

### 🏗 轻量但有深度的经营系统

* 建设 / 游客 / 经济 / 员工 / 研发 五大系统闭环
* 支持碎片化游玩 + 自动存档

---

## 🔁 核心游戏循环

```text
建造 → 吸引游客 → 产生收入 → 提升满意度
   ↓                              ↑
研发解锁 ← 扩张公园 ← 资源积累 ←——
```

---

## 🧩 核心系统

### 🏗 建设系统

* 网格化布局（最大 128×128）
* 多类型设施：

  * 刺激设施（过山车、跳楼机）
  * 温和设施（旋转木马、摩天轮）
  * 商业（餐饮）
  * 基础设施（厕所、长椅）
* 道路系统 + 寻路网络

---

### 🤖 游客 AI 系统

* 架构：FSM + Utility Score
* Web Worker 异步计算
* 行为：

  * 找设施 → 排队 → 游玩
  * 饥渴 → 消费
  * 疲劳 / 恶心 → 休息 / 急救
* 支持 1000 人级别模拟

---

### 💰 经济系统

* 收入：

  * 门票 / 设施收费 / 商品销售
* 支出：

  * 维护 / 员工 / 研发 / 贷款
* 满意度驱动增长：

  * ≥80：游客增长
  * <40：游客流失

---

### 👷 员工系统

* 类型：

  * 清洁工 / 修理工 / 保安 / 演艺人员
* 区域巡逻（非直接控制）
* 自动任务调度（Worker 内执行）

---

### 🔬 研发系统

* 投入资金 → 转换为研发点数
* 解锁：

  * 新设施
  * 服务升级
  * AI / 寻路优化
  * 自动定价系统

---

### 🌦 天气系统

* 动态天气影响：

  * 晴天：游客 ↑
  * 雨天：游客 ↓ / 户外设施关闭
* 提前预报 → 策略决策

---

## 🖥 UI / UX

* 3D 主视图（Babylon.js）
* React HUD：

  * 顶部状态栏（资金 / 时间 / 星级）
  * 底部建造栏
  * 右侧迷你地图
* 一键截图（1920×1080）
* 流畅建造交互（预览 / 旋转 / 连续铺设）

## 🧱 技术架构

### 技术栈

| 层    | 技术         |
| ---- | ---------- |
| 渲染   | Babylon.js |
| UI   | React 18   |
| 状态管理 | Zustand    |
| 并发   | Web Worker |
| 存储   | IndexedDB  |
| 构建   | Vite       |

---

### 架构分层

```
Presentation
 ├─ React HUD
 └─ Babylon Canvas

Game State
 └─ Zustand Store

Simulation (Web Worker)
 ├─ AI System
 ├─ Economy System
 ├─ Pathfinding
 └─ Staff System

Data Layer
 ├─ IndexedDB
 └─ localStorage
```

---

### ECS 模式

* **Entity**：游客 / 员工 / 设施
* **Component**：位置 / 需求 / 钱包 / 状态
* **System**：AI / 经济 / 寻路 / 员工

## ⚡ 性能优化

* Instanced Mesh（1000 游客 ≈ 4 draw calls）
* LOD（远距离降模）
* 对象池（垃圾 / 呕吐物）
* 增量 A* 寻路
* Worker 分片计算
* HUD 批量更新（非逐帧）

👉 目标：
**1000 游客 @ 30 FPS（集成显卡）**

---

## 💾 存档系统

* IndexedDB 存储完整 JSON
* 自动存档（每 5 分钟）
* 存档大小：

  * ~200KB（未压缩）
  * <50KB（压缩）
